字号按图片短边的百分比算，所以同一套设置在大图和缩略图上观感一致； 导出时按最终尺寸重绘，不会因为先缩放而糊掉。预览画的是「裁剪框内的区域」。
做法：把图缩到 64×64 采样，按每通道 4 bit 量化后统计出现频次， 取占比最高的 6 色（并合并相近色）；平均色单独算。点色块复制 HEX。 适合取「整体色调」，不适合当严格的主题色分析。

· 优化做四件事：去 XML 声明 / DOCTYPE / 注释、去 metadata 与 Inkscape、Sodipodi 等编辑器残留、 折叠标签间空白、按所选精度收敛数值。「text」「style」这类元素的内容原样保留（空白有语义）， 改完会做一次 XML 校验，校验不过就保留原文。
· 转 PNG 走 img + canvas，SVG 里若引用了外部图片或字体可能被判定为跨域而失败； 有些编辑器导出的 SVG 带未声明的命名空间前缀，XML 解析不通过时先点一次「优化」就能修好。 PNG 最长边封顶 4096 px，再大 canvas 会拖死浏览器。
