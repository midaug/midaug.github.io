类型长度随机位可排序说明
随机源一律是 crypto.getRandomValues（密码学安全），不用 Math.random() —— 后者的状态可被反推， 拿它生成的 ID 能被预测。
注意：UUID v7 / ULID / ObjectId 里嵌入的是「生成时刻」，会暴露创建时间；对外场景若不想泄露时间， 请用 v4 或 NanoID。
